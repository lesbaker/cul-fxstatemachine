# Culebra Functional State Machine

Prototype library for the [Culebra Programming Language](https://github.com/yhirose/culebra) that implements a functional state machine. Planned features are a isolate-backed runner, entry and exit handlers, and a multimethod-driven API.

If you don't know what the Culebra language is, go to the above link and prepare for your face to be melted off from the pure awesomeness of it. Or your mind blown. Or both.
